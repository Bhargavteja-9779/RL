\begin{abstract}
Dispatching rules such as earliest-deadline-first (EDF) and shortest-processing-time (SPT) assume constant processing capacity, which fails when the resource is a person whose attention depletes, whose fatigue accumulates and whose alertness follows a circadian rhythm. We formulate human-centric task scheduling as a partially observable Markov decision process in which rest is an explicit action, attention and fatigue are latent states observed only through noisy estimates, and the reward balances deadline-weighted task value against cognitive load. We propose an attention-aware deep reinforcement learning framework that approximates the belief state with an observation history, and instantiate it with a value-based learner (AA-DQN) and a policy-gradient learner (AA-PPO). In a literature-grounded simulator, both were compared with nine rule-based schedulers, including grid-tuned EDF and SPT rules with periodic or state-triggered rest, using ten training seeds, 500 held-out workdays with common random numbers, and multiplicity-corrected tests on reward-independent metrics. Rules that never rest performed poorly (EDF: \edfOnTimePct\% of tasks on time). AA-DQN matched the best tuned rule in return and completed more tasks on time. AA-PPO exceeded the best rule in return ($+\PpoRetSPTThreshold$, $p<10^{-4}$), on-time completion (\PPOOnTimePct\% versus \bestHeurOnTimePct\%) and difficulty-weighted on-time completion ($+\PpoWOnSPTThreshold$ percentage points). The learned policies alone combined high throughput with protection of demanding tasks, by doing hard work while attention is high and resting before and during the post-lunch dip. AA-PPO remained the best method under sensor noise, different worker profiles, heavier workloads and $\pm30\%$ changes of every cognitive parameter, whereas AA-DQN generalised poorly to unseen workloads.
\end{abstract}
