\subsection{Computational cost}\label{sec:cost}
Training one AA-DQN agent for 5000 simulated workdays took \trainTimeAA{}~s on average on a single CPU thread (vanilla DQN: \trainTimeDQN{}~s), including the periodic validation runs. The complete evaluation loop, including the Python simulator, takes about \inferUs{}~$\mu$s per decision when 500 days are evaluated in a batch. Even unbatched, inference is many orders of magnitude faster than the 10-minute decision interval, so the scheduler could run on a smartphone or wearable gateway. The heuristics are cheaper still, but their grid search (up to 252 parameter combinations $\times$ 300 days) must be repeated whenever the environment changes, just as the agent must be retrained.
