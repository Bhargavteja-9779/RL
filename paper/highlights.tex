\section*{Highlights}
\begin{itemize}
\item Human task scheduling is cast as a POMDP with latent attention and fatigue.
\item Rest breaks are explicit actions of a memory-augmented deep Q-network.
\item Tuned rest rules are strong; learned agents match or beat the best of nine.
\item Only learned policies protect hard tasks while maximising on-time completion.
\item The value of learning grows sharply with the accuracy of cognitive sensing.
\end{itemize}
